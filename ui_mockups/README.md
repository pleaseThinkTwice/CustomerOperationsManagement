# UI 界面样板（设计定调）

统一视觉：深蓝科技风 + 深浅双主题（深色默认，右上角一键切换，localStorage 记忆）。
两份样板共用同一套 CSS 令牌（配色 / 圆角 / 阴影 / 间距 / 主题），是全站可复用的设计系统。

| 文件 | 说明 |
|---|---|
| `platform-shell.html` | 整个平台定调页：侧栏导航（10 页）+ 顶栏筛选 + 首页看板（统计块 / 接入趋势 / 车辆洞察 / 失效模式表 / 关键人 / 拜访三色 / 会议） |
| `user-admin.html` | 用户与权限管理：用户表格 + 角色权限勾选矩阵 |

## 怎么用

纯 HTML/CSS/JS，无第三方框架，直接双击浏览器即可预览，也可当 Flask 模板。

落地建议：把两份文件顶部 `<style>` 里的令牌（`:root` / `[data-theme]` 块）抽成一个公共 `static/css/theme.css`，
全站页面统一 `<link>` 引用；组件类（`.panel` / `.tile` / `.btn` / `.badge` / 表格 / 侧栏 / 顶栏）即可跨页复用。

> 样板内数据为示例；接入真实接口后替换为 `/api/*` 数据即可。
