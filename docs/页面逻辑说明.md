| 项 | 逻辑 |

## 1. 首页看板（page1）

**定位**：客户全维度洞察，三个视角逐层下钻：客户视角（一个 OEM 全局）→ 项目视角（客户 × 电芯容量）→ 电芯视角（同一容量电芯跨客户对比）。

**顶部筛选**

| 视角 | 筛选项 |
|---|---|
| 客户视角 | 客户（可搜索） |
| 项目视角 | 客户 + 容量（项目） |
| 电芯视角 | 电芯容量 + 失效模式（可搜索，含「全部」） |
| 公共 | 时间：近 3 月 / 近 6 月 / 近 12 月 / 全部（只作用于走势图和质量分析，KPI 为历史累计）；「下载」把当前看板导出为独立 HTML；右侧悬停面板可保存 / 切换视图 |

**客户视角**

- KPI：累计出货（颗 / 包）、累计接入、pack_id 缺失率（缺失数 / 接入数）、过保数(率)（过保数 / 累计出货 Pack）、近 90 天活跃车辆、预警外发 / 已闭环（闭环率）、近 7 天预警 / 闭环。
- 接入走势（by 月 / by 年 / 近 15 天，均为当期接入量）；各容量出货 / 接入对比（分组柱，图例可点选）。
- 质量分析：预警外发 / 市场闭环 / 客诉三个指标，按失效模式堆叠走势（月增量 / 累积量），下方明细表 + 占比环形图；明细表「查看规则」跳到预警闭环对应规则。
- 项目排名（预警外发 / 市场闭环 / 接入数 / 过保数）、关键处置事件（可录入）、电芯项目表（点行进入项目视角）、关键人 / 拜访计划 / 近期会议（可新增，或跳到客户档案、会议纪要）。
- 下方「自定义模块」：用户自建柱状 / 折线 / 饼图 / 表格 / 数字卡片，数据手工录入或 AI 生成。

**项目视角**

- KPI：累计出货（Pack，含模组 / 电芯数）、累计接入（接入率 = 接入 / 出货 Pack）、pack_id 缺失率、近 15 天接入、过保数(率)、预警外发 / 已闭环、近 7 天预警 / 闭环。
- 项目接入走势、项目关键处置事件、质量分析（按失效模式）、SOH 衰减走势（按累计里程或累计循环数分桶的箱线图，可按 PN 看，叠加质保 SOH 门槛线）、适用车型 & 质保（车型级质保年限 / 里程 / SOH 可行内编辑）。
- 「下钻进入电芯视角」。

**电芯视角**

- KPI：电芯累计出货、接入车辆数、pack_id 缺失率、失效车辆数（= 现场工单数）、市场已闭环、失效率 ppm（失效车辆数 / 接入车辆数 × 10⁶）、今年接入。KPI 与跨客户对比合计同口径（各客户行求和）。
- 跨客户对比：出货(Pack) / 出货(Cell) / 出货占比 / 接入 / 今年接入 / pack_id 缺失率 / 预警外发 / 已闭环(率) / 失效车辆数 / 失效率(ppm · 较整体)；合计只加数量列，比率列留空；点行进入该客户的项目视角。
- 电芯失效率走势（ppm）：整体 + 各客户折线，右上角月增量 / 累积量切换，图例可点选。
- 失效模式构成：整体 + 各客户的失效电芯按失效模式百分比堆叠；点色块 / 图例即按该失效模式筛选整页，再点取消；筛选后仍显示全部构成并高亮选中项。
- SOH 分布：按客户分组柱状图（各客户各区间占比合计 100%），图例可点选。
- 质量分析：电芯视角按**客户**分组（走势图例、明细表、占比饼图），其余视角按失效模式。
- PN 追溯：PN 与客户多对多；柱状图按 PN 分组、客户分色；明细按 PN 合并单元格列出各客户出货颗数 / 失效颗数 / ppm / 状态。
- 异常电芯明细（高风险）、电芯批次关键处置事件。
- 失效模式筛选生效时：KPI 失效车辆数与 ppm、对比表、失效率走势、质量分析、PN 追溯失效颗数、异常电芯都按该模式重算；出货 / 接入不变。

**数据来源**：`/api/dashboard/three_view?view=customer|project|cell`，事件 `/api/events`，质保设置 `/api/warranty_settings`，自定义模块 `/api/dashboard/modules`。

## 2. 我的待办（page17）

- 汇总当前账号的三类事项：会议任务、认领的预警、部门需求（`/api/workbench/my_todos`）。
- 分类：待办（未完成的全部）/ 已完成 / 认领预警 / 部门需求 / 会议任务。
- 会议任务可直接改状态（待处理 / 进行中 / 已完成）；每条可跳到来源页面（预警 → 预警闭环，部门需求 → 部门需求池，会议任务 → 会议纪要）。

## 3. 系统导航（page15）

- ADG 现有系统清单卡片：名称、地址（可跳转）、用途、部署状态、权限管控、负责人；按状态分组，可搜索。
- 有 `page15.view` 权限的用户可前端新增 / 编辑 / 删除系统。

## 4. 客户档案（page2）

- 客户列表：OEM、客户名称、等级、客户关系；按名称 / OEM 关键词和等级筛选。
- 行操作：展开关键人（树形上下级）、详情（基本信息 / 拜访记录 / 合作协议 / 关键人四个页签）、编辑、删除（删除客户会级联删除关联数据）。
- 关键人：单个新增 / 编辑 / 删除，或按模板批量导入；可查看关键人关系图。
- 数据来源：OEM 由 Doris 播种，档案字段本地维护（`/api/customers`、`/api/key_persons`）。

## 5. 会议纪要（page3）

- 会议列表（按客户筛选、分页）：会议名称、客户、日期、记录人、目的。
- 新增 / 编辑：客户、标题、日期、内外部参会人、记录人、材料名、共识（多条）、待办任务（随会议一起保存，有草稿保护和本地草稿恢复）。
- AI 智能提取：粘贴纪要文本生成会议；批量智能提取：多文件批量生成。
- 行操作：详情、编辑、任务（负责人 / 计划日期 / 实际完成日期 / 状态，可单条通知）、下发通知（按负责人汇总未完成待办，通过「小哨兵」推送）、材料（上传 / 下载 / 删除归档材料）、导出 Excel、删除（级联删除共识、任务、材料）。
- 详情页可「转需求」：跳到需求管理并预填客户和来源会议。

## 6. 预警闭环（page4）

顶部：客户选择（联动各子页按客户筛选）、AI 分析。四个大 Tab：

### 6.1 常规预警

| 子页 | 逻辑 |
|---|---|
| 预警外发规则 | 规则主表（本地真源，Excel 导入）：OEM、容量、预警类型、车型、是否外发、不外发天数、阈值、不外发位置、维修建议、出货类型、状态、外发数量、TOP 排序、过保数量 / 是否外发、工单完成量等；可按客户 / 预警类型 / 状态 / 容量筛选，有 `warning.edit` 权限可增删改。首页质量分析「查看规则」会跳到这里并预筛。 |
| 质保信息管理 | **质保统览**：按 OEM × 电芯容量 × PN 统计车辆数、在保、过保、过保率，带合计。**质保信息管理**：每个 OEM × 电芯容量 × PN 维护质保年限 / 质保里程 / 质保 SOH，可新增 / 编辑 / 删除 / 上传；**更新记录**记下改前改后与过保数变化。车辆在保 / 过保按所属 PN 的质保信息判定：交付日 + 质保年限已过，或里程超出质保里程，任一即过保。质保 SOH 目前只维护和展示。 |
| 不外发车辆管理 | 上传不外发清单（固定模板）或手动新增 / 移除；每条带原因与有效期，过期自动恢复；清单内车辆在外发判定中排除。 |
| 风险批次管理 | 方式一：基地 → 拉线（联动）→ 生产时间 →「查询涉及客户」，只列出该线该时段供货的客户及车辆数，选客户后可下载清单或直接提交；方式二：按模板上传风险批次清单后提交。提交后只登记，由算法人员按清单与算法结果后续预警；批次列表可查看 / 下载清单、删除。 |

人为脱保已在 GSS 实现，不单独展示，只作为外发排除条件。

### 6.2 非常规外发

1. 载入清单：上传固定模板文件、载入示例，或导入复核任务中勾选外发的车辆。
2. 外发规则（可勾选）：排除售后工单（近 N 月）、人为脱保（GSS）、过保（里程 / 年限阈值）、近 N 日已外发、不外发清单。
3. 排序依据列 + 从大到小 / 从小到大；外发数量（条 / 日）；最早开始 / 最晚结束外发日期。
4. 内部复核预警原因（下拉）→ 客户预警原因自动带出。
5. 提交后显示外发漏斗（每条规则排除多少）与按日排程，可看每天明细；确认外发后生成批次记录，并回写车辆「最近外发」日期（下次按「近 N 日已外发」排除）。

### 6.3 复核闭环

| 子页 | 逻辑 |
|---|---|
| 复核规则管理 | 复核项（自放电 / 绝缘 / 温差 / 电压）的判定逻辑、阈值、观察窗口、默认处置建议、默认外发；可编辑、启停。停用的复核项在登记时不可选。 |
| 复核登记 | 上传批量复核文件 + 复核类别（多选）+ PM + 指定复核人 + 最晚交付日期 + 备注 → 确认提交生成任务编码（`YYYYMMDD-NNN`），下方为登记记录。 |
| 复核确认 | 任务列表（任务编码、最晚交付日期、车辆数、复核项、PM、复核人、进度、状态：未完成 / 已完成 / 已逾期、外发 / 转发数）→ 任务详情：每台车每个复核项一行，策略图（可放大）、结论、处置建议、外发、转发给组、挂起。选结论后按复核规则带出默认处置与外发；挂起行锁定且不计入完成校验；确认提交前校验结论和处置建议必填。提交后勾选外发的车辆可导入非常规外发，导入后任务标记「已外发」。 |

### 6.4 预警记录

- Doris 预警按容量 × 失效模式聚合 + 本地闭环维护（闭环状态、未闭环原因、处置动作、外发逻辑），可新增 / 编辑。

## 7. 阶段总结（page5）

- 按客户 + 日期范围（默认本月）查询阶段性总结记录：客户、日期、失效模式、预警外发数量、预计降低抛锚数、里程碑。
- 顶部统计：记录总数、失效模式类型数、预警外发总数、预计降低抛锚数。
- 操作：标记 / 取消里程碑（可填说明）、导出周报（Excel）、导出 HTML 报告、发送邮件（收件人 / 抄送 / 主题）。

## 8. Q&A 知识库（page6）

- 左侧智能问答：输入问题检索知识。
- 右侧管理：Q&A 记录（分类、问题、维护人，可新增 / 编辑 / 删除 / 导入 / 导出）；知识库管理（QA 库 / 数智分析库两套，按分类树浏览、上传、同步 Q&A、同步文件夹、重建、AI 补全）。

## 9. 数智分析（page9）

- 自然语言提问，Agent 以 SQL + Python 多步分析，展示思考过程与结果表 / 结论；可追问、编辑重答、点赞点踩、收藏为常用问题。
- 高级区：常用问题快照（可批量生成多问题报告）、数据查看（预置视图，可导出 CSV）、可查表目录（看字段、看数据、导出目录）、自定义知识。
- 入口按钮：工具箱、查询手册。

## 10. 工具箱（page19）

- 运营常用查询工具按分类分组；填参数（文本 / 数字 / 下拉 / 客户 / 按客户联动的容量）后执行，返回结果表。
- 管理员可新增 / 编辑 / 删除工具定义（名称、说明、参数、SQL 模板、结果列）。

## 11. 知识中心（page18）

- 统一入口，页签：常用速查（`docs/常用表.md`、`docs/常用知识.md`）、查询手册（references）、Q&A 知识库、数智分析知识库、数据洞察；每次进入刷新当前页签，可「在数智分析里问」。

## 12. 数据洞察（page14）

- 让 Agent 学习表结构并沉淀「数据知识」：学单张表、批量学习（多线程）、已学表列表（收藏、重新学习、查看报告、导出、删除）。
- 总览：数据资产域、信号与跟进看板（推进跟进状态）、跨表联动、数据资产速查（按业务字段搜表）。
- 可同步到数智分析知识库、生成报告、导出汇总 Markdown。

## 13. 文档管理（page7）

- 书架按 客户（OEM）→ 电芯容量（无容量归「通用」）→ 文档类型 三级分组；文档类型固定为数据委托处理协议 / 数据转发费用协议 / 阳光协议。
- 按客户 / 容量 / 类型筛选；上传（客户、类型必填，容量可选）；点书本下载。

## 14. OEM 映射（page8）

- 维护客档表 `oem` ↔ 出货表 `cust_grp_name` 的映射；下拉候选来自 Doris（只读），映射存本地。
- 列表按 OEM 筛选；可新增、删除。

## 15. 需求管理（page10）

- 需求列表：ID、标题、来源客户、背景说明、标签、责任人、优先级、计划时间、状态、操作。
- 新增 / 编辑：标题、来源客户、来源会议、说明、标签、责任人（姓名 + 工号，用于推送）、优先级（低 / 普通 / 高）、计划时间。
- 审批（`demand.approve`）：待审批 / 已驳回的需求可通过或驳回，通过时可选择推送通知责任人；删除需 `demand.delete`。
- AI 智能拆解：粘贴会议纪要 / 客户需求文本，生成多条需求草稿，确认后批量入库。会议纪要「转需求」进入这里。

## 16. 部门需求池（page16）

- 面向大数据部门内部、不关联 OEM：提需求（材料为文本说明）→ 授权审批人任一审批 → 排期 / 责任人 → 完成（填完成时间）。
- 统计卡与筛选：全部 / 待审批 / 已通过 / 已驳回 / 已完成，可只看我的；被驳回的需求提报人可修改后重新提交。

## 17. 系统管理（page11）

- 用户权限管理：每个用户可访问的客户（OEM 多选）、账号状态、管理员自定义的动态列（可增删）、可见页面配置。
- 用户列表（新增 / 编辑 / 启停 / 删除；编辑时可改密码，新用户默认初始密码 123456，首次登录强制修改）、角色说明（按角色配置可见页面）、登录日志、操作日志、行为频率统计（页面访问 / 问题查询，按用户 × 对象累计）。

## 18. 合同管理（page12）
