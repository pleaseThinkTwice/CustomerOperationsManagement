# 公司内部数据助手：现成产品与 SQLBot 演示评估

更新日期：2026-10-26

## 1. 目标与结论

目标是让员工通过一个聊天入口，既能查询公司 SQL、QA 与业务口径文档，也能提出数据需求，由系统生成 SQL、查询结果，并在需要时创建可复用的数据工作流。用户不必选择“文档问答”或“数据库问答”；系统内部仍需根据问题分别调用文档、数据库或两者协同。

本次已部署原版 SQLBot v1.10.2，并完成了数据源、术语、SQL 示例和真实数据预览的演示。SQLBot 适合作为**智能问数模块**直接复用。它的术语库和 SQL 示例可以为 Text-to-SQL 提供业务上下文；目前没有证据表明原版能完整覆盖任意文档 QA 与自动创建调度工作流。2026-10-26 已另外直接调用 DeepSeek API 做三条合成数据问答测试，结果见第 4 节。如果你们最终最看重“说一句需求就生成数据开发工作流”，阿里 DataWorks Data Agent 与腾讯 DataBuddy 更值得做产品试用。

## 2. 已经跑通的演示

| 项目 | 实际结果 |
| --- | --- |
| 软件 | 官方 SQLBot v1.10.2，源码提交 `aa41fc1033bb974a703df9200a98ec8b9eec5f25`，应用源码未修改 |
| 部署 | 原版 Web、后端和 PostgreSQL 启动，浏览器登录成功 |
| 数据源 | 创建只读 PostgreSQL 数据源；识别 `orders`、`order_items`、`refunds` 三张表 |
| 业务知识 | 将“净销售额”及同义词“净收入”保存到术语库，绑定演示数据源 |
| SQL 示例 | 保存“2026 年 9 月净销售额”问题与参考 SQL |
| 数据预览 | 浏览器真实读取 6 条订单，其中包含取消订单和退款订单 |
| 参考查询 | 人工编写的 SQL 实际返回净销售额 **2900.00 元** |

以上数据全部为本地合成数据。2900 元是人工参考 SQL 的结果，**不是大模型答出的结果**。

## 4. DeepSeek API 实测与尚未验证的能力

使用用户提供的 DeepSeek Key 直接调用 `deepseek-chat` 接口，服务返回模型标识 `deepseek-flash`。只传输了合成数据的表结构与业务规则，没有传输公司资料。模型生成的 SQL 先经过单条只读语句检查，再以数据库只读角色执行。测试时保存了不含 Key 的本地核验记录；本次 GitHub 提交只包含本报告和截图。

| 问题 | 模型行为 | 数据库执行结果 | 参考结果 |
| --- | --- | ---: | ---: |
| 2026 年 9 月净销售额 | 生成单条只读 SQL | 2900.00 | 2900.00 |
| 购买了鼠标的订单毛销售额 | 使用 `EXISTS` 避免订单明细重复统计 | 2300.00 | 2300.00 |
| 销售额是多少 | 追问毛销售额还是净销售额 | 未查询 | 应追问 |

这三条**是直接调用 DeepSeek API 的测试，不是 SQLBot 界面里调用模型的测试**。样本很少，不能据此推断生产准确率。

以下能力仍未验证：

| 能力 | 状态 | 原因或下一步 |
| --- | --- | --- |
| SQLBot 内自然语言问数 | 未测 | DeepSeek API 已单独测通，但尚未在 SQLBot 中配置该模型 |
| SQLBot 内自动追问 | 未测 | DeepSeek API 单独测试能追问；产品内流程尚未验证 |
| 通用 SQL/QA 文档问答 | 未测 | 已验证术语与 SQL 示例，不能等同于任意文档检索问答 |
| 一句话创建、发布数据工作流 | 未实现 | 不是本次 SQLBot 演示提供的能力 |
| 公司数据库适配和业务准确率 | 未测 | 尚未接入公司真实数据；示例仅能验证流程与界面 |

后续建议继续覆盖这些边界案例：取消订单、多笔退款、明细表导致重复统计、用户需求歧义、空数据及禁止写入。先用这些案例实测，再决定产品是否足够可靠。

## 5. 产品选择建议

| 候选 | 适合的重点 | 核实过的依据 |
| --- | --- | --- |
| SQLBot | 快速复用中文智能问数产品，包括 SQL、图表、术语库与示例 SQL | [官方仓库](https://github.com/dataease/SQLBot)、本地演示 |
| 阿里 DataWorks Data Agent | 数据开发闭环：澄清需求、探查数据、生成 SQL、创建和调试工作流 | [官方文档](https://help.aliyun.com/zh/dataworks/user-guide/data-coder-agent) |
| 腾讯 DataBuddy | 数据分析与工程 Agent、知识库、工作流及失败诊断 | [产品功能](https://cloud.tencent.com/document/product/1835/135579)、[知识库](https://cloud.tencent.com/document/product/1835/137996) |

下一轮试用若以“一个入口同时问文档和数据”为第一目标，应专门验证文档问答与 SQL 查询能否在同一轮问题中组合。若以“自然语言生成工作流”为第一目标，应先试 DataWorks Data Agent 或 DataBuddy，避免把 SQLBot 的问数功能误认为完整数据工程交付。
