# CustomerOperationsManagement

这是一个基础的客户运营管理项目初始化模板，已搭建最小可运行的 Node.js 服务。

## 目录结构

- `src/server.js` - 服务入口
- `package.json` - 项目脚本配置

## 快速开始

```bash
npm install
npm start
```

启动后访问：

- http://localhost:3000/
- http://localhost:3000/health

## 开发模式

```bash
npm run dev
```

该模板可作为后续功能开发的基础骨架，后续可以扩展客户管理、工单、运营报表等模块。
