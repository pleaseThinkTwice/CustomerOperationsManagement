# 星风冒险

原创的单机横版 2D 动作小游戏。电脑上直接双击 `index.html` 即可玩；也可以在本目录运行 `python -m http.server 8000`，打开 `http://localhost:8000`。没有依赖、账号或联网请求。

![游戏画面](assets/preview.png)

| 按键 | 操作 |
| --- | --- |
| A / D 或 ← / → | 左右移动 |
| 空格、W 或 ↑ | 跳跃、二段跳 |
| J | 连击 |
| K | 冲刺，短暂无敌 |
| L | 星光满格后释放范围爆发 |
| P | 暂停 / 继续 |

穿过云杉谷地，击败守门巨灵后进入星门。沿途旗帜是复活点；进度保存在当前浏览器的 `localStorage`。音效可在页面右上角关闭。游戏使用 Canvas 绘制原创场景和角色，没有使用《冒险岛》的素材或角色。

## 开发

页面、样式和游戏逻辑分别位于 `index.html`、`style.css`、`game.js`。修改后刷新页面即可看到效果。
